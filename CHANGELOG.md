# Changelog

## 2.0.0 — Atjazz classic dark edition

- Retained the original control sprites, bitmap fonts, positions and 570 × 500
  editor geometry; restored classic controls after a broader redesign.
- Darkened the pale panel, added the supplied transparent Atjazz Record Company
  mark and updated version/vendor metadata.
- Made the version and Randomize lettering white.
- Kept the existing Camel Space 2 VST3 class IDs, bank/state formats, original
  engine and Rosetta helper for this appearance update.

## Earlier local revival baseline

- Added the native ARM64 VST3 front end and per-instance Intel/Rosetta engine
  helper, preserving original parameters, presets, tempo, MIDI and state.
- Recovered the obsolete support archive without running the installer.
- Added native editor rendering, FXP/FXB and CSP operations, tests and a
  backup-preserving local installer.

## Public source import — 24 November 2026

- Published Camel Space 2 as a standalone project, separate from other plug-ins.
- Added source setup, installation, compatibility, support and licence guidance.
- Kept original commercial runtime files, local builds and raw logs outside Git.
