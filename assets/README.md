# Atjazz Record Company artwork

`atjazz-record-company.png` is an unchanged copy of the user's existing
`ARCo-Hi-Res-Scribble-Black-Trans.png`, supplied for this project.

SHA-256: `e0ff9de13557764daa9f488f3ed2de2e369c3bc8bb7f95794df989b24a8dc1f3`.

The original 595 × 842 PNG has genuine alpha transparency. The native renderer
uses that alpha to draw a light logo on the dark background, arranging its
symbol and wordmark horizontally. No white rectangle is added and the image
file is not regenerated or edited. Logo rights remain with its owner.
